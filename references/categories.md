# 类别表（categories.md · 通用模板）

> 本文件是 **skill 自带的通用模板**，可直接分享给同事复用。
> 你个人的真实分类表应放在 `<DATA_ROOT>/categories.md`（首次运行【MODE=setup】会复制本模板过去，
> AI 后续摄取待办时自动学习并填充你的父任务别名）。
> 词表没有的新值，AI 应**提议**并由你确认后补入，不擅自创造规范值。

---

## 一、父任务别名表（alias → 规范父任务名）【个人字段：首次由 setup 复制本模板后自行填写】

AI 看到别名时归入对应规范父任务；未命中则归入 `其他`，或遇明显新项目时提议新增。

```
# 示例（删掉注释后改成你自己的项目）：
# 我的项目A:        [项目A别名1, 项目A别名2]
# 我的项目B:        [项目B别名1, 协作人甲, 协作人乙]
其他:              [*]   # 兜底
```

> 说明：下方"人名"仅用于"人名自动抓"——出现在待办文字里时写入 `assignee`，**不代表项目归属**。

---

## 二、type 受控词表（待办类型）【通用，一般无需改】

AI 归类时从下表选**最贴切**的一个；都不贴切用 `其他`。

| 规范值 | 含义 / 典型例子 |
|--------|----------------|
| 需求 | 需求梳理、PRD、角色/权限规划 |
| 开发 | 系统开发、脚本、配置、接口 |
| 采购 | 采购立项、招标、合同、供应商管理 |
| 审批 | 用印、合同审批、流程审批 |
| 会议 | 周例会、评审会、对齐会 |
| 文档 | 改名方案、材料撰写、制度文档 |
| 沟通 | 协调、请评估、同步、找人要材料 |
| 运维 | 数据导入导出、批量处理、例行运维 |
| 其他 | 兜底 |

---

---

## 四、扩展约定

- 新增父任务：AI 提议规范名 + 别名清单，你确认后写入第一节。
- 新增 `type`/`source` 值：同上，确认后补入第二节/第三节。
- 本文件只增不改既有规范值（避免历史数据归类漂移）。
